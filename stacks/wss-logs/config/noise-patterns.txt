# Noise-patronen voor Docker error-kaarten (één regex-alternatie, !~ filter).
# SOURCE OF TRUTH — staat in elke docker-error query als:
#   !~ "level=info|level=debug|scheduler_processor|context canceled|entry too far behind"
# Toevoegen = `|patroon` aan de alternatie toevoegen in ALLE error-exprs:
#   provisioning/dashboards/wss-logs.json        (panels 6, 7)
#   provisioning/dashboards/wss-containers.json  (panel 2)
#   provisioning/dashboards/wss-overall.json     (panels 3, 7)
# Regels:
# - Alleen patronen uitsluiten die BEWEZEN ruis zijn (restart/query-cancel/duplicaat-push).
# - NOOIT een heel container- of severity-niveau wegfilteren.
# - Echte/onbekende errors blijven zichtbaar - die zijn juist het doel van de kaart.
#
# Actieve patronen:
level=info            # info-regels met het woord "error" in de tekst
level=debug           # idem voor debug
scheduler_processor   # Loki shutdown-bursts (context canceled per worker)
context canceled      # afgebroken Grafana/Loki queries
entry too far behind  # Alloy duplicaat-pushes na restart/reload
failed to tail file  # Alloy file-source bij restart/missende target
empty ring           # Loki ingester-ring tijdens opstarten
apis/quotas          # Grafana interne quota-API 5xx chatter
has timestamp too old   # Loki reject op verlopen/gedupliceerde pushes (replay na restart, zelfde familie als 'entry too far behind')
ingestion rate limit exceeded  # Loki distributor rate-limit bursts (interne Loki-ruis)
no retries left       # Alloy dropt batches rond Loki-restart/overload ('final error sending batch')
Parse Error: Header overflow  # homarr2 ping/HTTP-client artifact (190x/5u) — Node parse-error op app-health checks
cleaning up inactive secure values  # Grafana interne secure-values cleanup job faalt op sqlite-lock (~19x/10u)
use of closed network connection   # Grafana->Loki query-cancel (client weg): 'read tcp ... closed' familie
throwGeneralAxiosError   # uptime-kuma axios stack-trace frames (elke mislukte notificatie -> meerdere 'at ...notification-provider.js' regels; duplicaat-push)
Cannot send notification to   # uptime-kuma meldt mislukte aflevering via Pushover/webhook — monitoring-artifact; echte down-signalen blijven via site-app KUMA_DOWN zichtbaar
EAI_AGAIN api.pushover.net   # uptime-kuma DNS-fail op de Pushover-pushpath; gescoped op pushover zodat echte DNS-ruis naar andere hosts zichtbaar blijft
database is locked   # Grafana SQLITE_BUSY-contention familie (~100x/24u): sqlstore.max-retries-reached retries in authn/ngalert/provisioning/bleve/ssosettings/cleanup — transient, herstelt elke cyclus (precedent: 'cleaning up inactive secure values')
Failed to write gzipped response   # middleware.gzip client-abort/UI-artifact (~12-20x/24u, recurring): browser/proxy verbreekt tijdens gzip-write, geen app-impact
